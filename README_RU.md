# MCPE Overlay (Android)

Плавающая Android-панель с шестью демонстрационными переключателями. Это рабочая overlay-оболочка, а не внедрённый игровой чит: Android не предоставляет приложению доступ к координатам игрока или внутренним параметрам Minecraft через разрешение «поверх других приложений».

## Сборка

Проект использует Gradle и Android Gradle Plugin 8.6.1, Java 17 и Android SDK Platform 35. На обычном Termux для Android SDK часто нет полноценного официального набора инструментов для сборки APK. Если у вас уже настроен SDK, из каталога проекта выполните:

```sh
gradle assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Если SDK в Termux не установлен, загрузите проект в свой GitHub-репозиторий и запустите workflow **Build Android APK** во вкладке Actions. Сборка использует GitHub-hosted Ubuntu runner, а не телефон.

## Установка

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Либо откройте APK в файловом менеджере Android и подтвердите установку. Запустите MCPE Overlay, выдайте разрешение «Поверх других приложений», нажмите кнопку запуска, затем откройте Minecraft.

## Возможности

- Плавающая кнопка, которую можно перетаскивать.
- Панель с переключателями Coords, Fullbright, Zoom, Speed, ESP и Fly.
- Корректное закрытие overlay-службы при остановке процесса.

Переключатели пока демонстрационные и не меняют состояние игры.
